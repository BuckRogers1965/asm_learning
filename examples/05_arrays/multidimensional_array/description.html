Two-dimensional arrays and row-major order storage.

Key Concepts:

  • Row-Major Order: C stores 2D arrays in row-major order (all elements of row 0, then row 1, etc.)
  • Index Calculation: Element [i][j] is at offset (i * num_columns + j) * element_size
  • Nested Loops: Accessing 2D arrays typically uses nested loops in assembly
  • Cache Efficiency: Row-major access patterns are more cache-friendly
