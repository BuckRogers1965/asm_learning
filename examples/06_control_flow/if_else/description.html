Simple if-else statement showing conditional branching.

Key Concepts:

  • Comparison: The cmp instruction compares two values and sets flags
  • Conditional Jump: Instructions like jle (jump if less or equal) branch based on flags
  • Labels: Branch targets are represented as labels in assembly
  • Fall-through: If the condition is false, execution continues to the next instruction
