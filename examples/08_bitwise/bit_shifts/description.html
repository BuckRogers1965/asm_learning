Left and right bit shift operations.

Key Concepts:

  • Left Shift: The shl instruction shifts bits left (multiply by 2^n)
  • Right Shift: The shr instruction shifts bits right unsigned (divide by 2^n)
  • Arithmetic Shift: sar preserves the sign bit for signed integers
  • Shift Amount: Usually specified in the cl register or as immediate
