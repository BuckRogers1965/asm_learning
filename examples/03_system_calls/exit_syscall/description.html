Using the syscall()

Key Concepts:

  • Exit Codes: Programs return a status code to the shell (0 = success, non-zero = error)
  • System Call Numbers: Each system call has a unique number (SYS_exit is defined in system headers)
  • No Return: The exit system call terminates the process, so code after it never executes
  • syscall() Wrapper: This libc function provides a generic interface to make any system call
