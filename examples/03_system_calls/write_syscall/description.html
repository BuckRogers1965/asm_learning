Using the write() system call to output text directly to stdout. This bypasses the standard library and talks directly to the kernel.

Key Concepts:

  • System Calls: A mechanism for user programs to request services from the kernel
  • File Descriptors: File descriptor 1 is standard output (stdout)
  • Direct Kernel Access: Unlike printf which uses buffered I/O, write() goes straight to the kernel
  • Calling Convention: System calls on Linux use the syscall instruction with arguments in specific registers
