A simple "Hello, World!" program using printf. This example shows the basic structure of a C program and how function calls work in assembly.

Key Concepts:

  • Function Call Setup: Arguments are passed to functions using registers or the stack, depending on the calling convention
  • String Constants: The string literal is stored in the .rodata section (read-only data)
  • Return Value: Functions return values in the eax/rax register on x86/x64
