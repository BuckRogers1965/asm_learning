Volatile keyword preventing compiler optimization of variable access.

Key Concepts:

  • Volatile Qualifier: Tells the compiler the variable may change unexpectedly
  • No Optimization: The compiler must always read/write the actual memory location
  • Hardware Registers: Often used for memory-mapped I/O and hardware registers
  • Side Effects: Ensures all reads and writes happen as specified in code
