Function marked as inline (may be inlined by compiler even at -O0).

Key Concepts:

  • Inline Hint: The inline keyword suggests the compiler should inline the function
  • Function Inlining: The function body is inserted directly instead of a call
  • Trade-offs: Inlining eliminates call overhead but increases code size
  • Compiler Decision: The compiler decides whether to actually inline
