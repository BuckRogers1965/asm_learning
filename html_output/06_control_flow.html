Conditionals, loops, and branching in assembly

For Loop

For loop showing initialization, condition, and increment in assembly.

Key Concepts:

  • Loop Counter: A variable (often in a register) tracks the loop iteration
  • Three-Part Structure: Initialization, condition check, and increment are separate instructions
  • Optimization Potential: Compilers can optimize loops significantly with higher optimization levels
  • Loop Unrolling: At higher optimization, compilers may unroll loops for performance

Reference: Wikipedia - Loop optimization

C Code

int main() {
    int sum = 0;
    
    for (int i = 0; i < 10; i++) {
        sum += i;
    }
    
    return sum;
}

If Else

Simple if-else statement showing conditional branching.

Key Concepts:

  • Comparison: The cmp instruction compares two values and sets flags
  • Conditional Jump: Instructions like jle (jump if less or equal) branch based on flags
  • Labels: Branch targets are represented as labels in assembly
  • Fall-through: If the condition is false, execution continues to the next instruction

Reference: Wikibooks - X86 Assembly Control Flow

C Code

int main() {
    int x = 10;
    int result;
    
    if (x > 5) {
        result = x * 2;
    } else {
        result = x + 1;
    }
    
    return result;
}

Switch Statement

Switch statement showing jump tables or conditional chains.

Key Concepts:

  • Jump Table: For dense cases, the compiler may generate a jump table for O(1) lookup
  • Conditional Chain: For sparse cases, the compiler uses a series of comparisons
  • Default Case: The default case is the fall-through when no case matches
  • Compiler Optimization: The compiler chooses the most efficient implementation

Reference: Wikipedia - Branch table

C Code

int main() {
    int x = 2;
    int result;
    
    switch(x) {
        case 1:
            result = 10;
            break;
        case 2:
            result = 20;
            break;
        case 3:
            result = 30;
            break;
        default:
            result = 0;
    }
    
    return result;
}

While Loop

While loop demonstrating backward branching and loop conditions.

Key Concepts:

  • Loop Structure: Loops use labels and jump instructions to repeat code
  • Condition Check: The loop condition is checked before each iteration
  • Backward Jump: The jump instruction goes backward to the start of the loop
  • Loop Exit: When the condition fails, execution continues past the loop

Reference: Wikibooks - X86 Assembly Control Flow

C Code

int main() {
    int count = 0;
    int i = 0;
    
    while (i < 10) {
        count += i;
        i++;
    }
    
    return count;
}
