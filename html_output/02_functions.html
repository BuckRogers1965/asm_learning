Recursive

A recursive function computing factorial. This shows how the stack builds up with multiple function calls and how each call maintains its own stack frame.

Key Concepts:

  • Stack Frames: Each function call creates a new stack frame containing local variables and the return address
  • Recursion: The function calls itself, creating nested stack frames that unwind as the recursion completes
  • Base Case: The conditional check that stops the recursion translates to a compare and conditional jump
  • Call Stack: The call instruction pushes the return address onto the stack; ret pops it and jumps back

References: CS161 - x86 Assembly and Call Stack, Learn Vulnerability Research - Stack Frame

C Code

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int main() {
    return factorial(5);
}

Simple Function

A simple function with parameters and a return value. This demonstrates the x86-64 calling convention where arguments are passed in registers.

Key Concepts:

  • Argument Passing: On x86-64, the first six integer arguments are passed in registers: rdi, rsi, rdx, rcx, r8, r9
  • Function Prologue: The standard entry sequence that sets up the stack frame (push rbp; mov rbp, rsp)
  • Function Epilogue: The exit sequence that cleans up and returns (pop rbp; ret)
  • Return Values: Integer return values go in rax (32-bit values use eax)

References: Wikipedia - Function prologue and epilogue, Sanfoundry - Function Prologue and Epilogue
