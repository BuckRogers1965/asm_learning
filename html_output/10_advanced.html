Function Pointer

Using function pointers for indirect function calls.

Key Concepts:

  • Function Pointers: Variables that hold the address of a function
  • Indirect Call: The call instruction uses a register instead of immediate address
  • Runtime Selection: The actual function called can be determined at runtime
  • Callbacks: Function pointers enable callback mechanisms and dynamic dispatch

Reference: Wikipedia - Function pointer

C Code

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int main() {
    int (*operation)(int, int);
    operation = &add;
    int result = operation(10, 5);
    return result;
}

Inline Function

Function marked as inline (may be inlined by compiler even at -O0).

Key Concepts:

  • Inline Hint: The inline keyword suggests the compiler should inline the function
  • Function Inlining: The function body is inserted directly instead of a call
  • Trade-offs: Inlining eliminates call overhead but increases code size
  • Compiler Decision: The compiler decides whether to actually inline

Reference: Wikipedia - Inline expansion

C Code

static inline int square(int x) {
    return x * x;
}

int main() {
    int a = 5;
    int b = square(a);
    return b;
}

Volatile Variable

Volatile keyword preventing compiler optimization of variable access.

Key Concepts:

  • Volatile Qualifier: Tells the compiler the variable may change unexpectedly
  • No Optimization: The compiler must always read/write the actual memory location
  • Hardware Registers: Often used for memory-mapped I/O and hardware registers
  • Side Effects: Ensures all reads and writes happen as specified in code

Reference: Wikipedia - Volatile (computer programming)

C Code

int main() {
    volatile int x = 10;
    x = x + 5;
    x = x + 3;
    return x;
}
