Pointer Arithmetic

Array access using pointer arithmetic. In C, arr[i] is equivalent to *(arr + i).

Key Concepts:

  • Array to Pointer Decay: Array names automatically convert to pointers to their first element
  • Pointer Arithmetic: Adding to a pointer moves by (number × element size) bytes
  • Scaled Indexing: Modern x86 processors have addressing modes that combine base + offset × scale in one instruction
  • Memory Layout: Arrays are stored as contiguous blocks in memory, enabling efficient sequential access

Reference: Baby steps in x86 assembly

C Code

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int *ptr = arr;
    int second = *(ptr + 1);
    return second;
}

Pointer Basics

Basic pointer operations: taking the address of a variable (&) and dereferencing (*).

Key Concepts:

  • Memory Addresses: Variables are stored at memory locations; pointers hold these addresses
  • Address-of Operator (&): Compiles to the lea (load effective address) instruction
  • Dereference Operator (*): Compiles to a mov instruction that reads from the memory address
  • Pointer Variables: Stored on the stack just like regular variables, but contain addresses

Reference: Lindevs - Generate Assembly Code using gcc

C Code

int main() {
    int x = 42;
    int *ptr = &x;
    int y = *ptr;
    return y;
}
