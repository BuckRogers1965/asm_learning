Overview

Composite data types and their memory layout

Simple Struct

Basic structure showing member access and memory layout.

Key Concepts:

  • Struct Layout: Members are laid out sequentially in memory
  • Member Access: Accessing members uses fixed offsets from the struct base address
  • Padding: The compiler may insert padding between members for alignment
  • Stack Allocation: Struct instances on the stack are allocated like arrays

Reference: Wikipedia - Data structure alignment

C Code

struct Point {
    int x;
    int y;
};

int main() {
    struct Point p;
    p.x = 10;
    p.y = 20;
    return p.x + p.y;
}

Struct Pointer

Accessing struct members through pointers.

Key Concepts:

  • Arrow Operator: The -> operator dereferences the pointer and accesses the member
  • Address Calculation: Member access adds the offset to the pointer value
  • Indirect Access: The assembly uses the pointer register plus offset
  • Equivalent Operations: ptr->member is equivalent to (*ptr).member

Reference: GeeksforGeeks - Structure member alignment and padding

C Code

struct Point {
    int x;
    int y;
};

int main() {
    struct Point p = {5, 10};
    struct Point *ptr = &p;
    return ptr->x + ptr->y;
}
