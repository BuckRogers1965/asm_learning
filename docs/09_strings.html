Working with C strings and character arrays

String Copy

Copying a string from source to destination.

Key Concepts:

  • Character-by-Character: Strings are copied one byte at a time
  • Include Null: The null terminator must be copied to properly terminate the destination
  • Pointer Increment: Pointers advance through both source and destination
  • Loop Termination: The loop stops after copying the null terminator

Reference: Linux man page - strcpy

C Code

void string_copy(char *dest, const char *src) {
    int i = 0;
    while (src[i] != '\0') {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';
}

int main() {
    char src[] = "Test";
    char dest[10];
    string_copy(dest, src);
    return dest[0];
}

String Length

Computing string length by iterating until null terminator.

Key Concepts:

  • Null Termination: C strings end with a '\0' character
  • Character Access: Strings are char arrays accessed byte-by-byte
  • Loop Until Zero: The loop continues until it finds the null terminator
  • Byte Operations: Character operations use byte-sized instructions

Reference: Wikipedia - Null-terminated string

C Code

int string_length(const char *str) {
    int len = 0;
    while (str[len] != '\0') {
        len++;
    }
    return len;
}

int main() {
    return string_length("Hello");
}
