Array Initialization

Array initialization and how the compiler handles constant data.

Key Concepts:

  • Stack Allocation: Arrays are allocated on the stack with space reserved by adjusting the stack pointer
  • Initialization Loop: The compiler may use loops or direct moves to initialize array elements
  • Memory Layout: Array elements are stored contiguously in memory
  • Alignment: Arrays may be aligned to word boundaries for performance

Reference: Wikipedia - Data structure alignment

C Code

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += arr[i];
    }
    return sum;
}

Multidimensional Array

Two-dimensional arrays and row-major order storage.

Key Concepts:

  • Row-Major Order: C stores 2D arrays in row-major order (all elements of row 0, then row 1, etc.)
  • Index Calculation: Element [i][j] is at offset (i * num_columns + j) * element_size
  • Nested Loops: Accessing 2D arrays typically uses nested loops in assembly
  • Cache Efficiency: Row-major access patterns are more cache-friendly

Reference: Wikipedia - Row and column-major order

C Code

int main() {
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };
    int sum = matrix[0][1] + matrix[1][2];
    return sum;
}
