Fundamental assembly patterns for simple operations

Hello World

A simple "Hello, World!" program using printf. This example shows the basic structure of a C program and how function calls work in assembly.

Key Concepts:

  • Function Call Setup: Arguments are passed to functions using registers or the stack, depending on the calling convention
  • String Constants: The string literal is stored in the .rodata section (read-only data)
  • Return Value: Functions return values in the eax/rax register on x86/x64

Reference: GeeksforGeeks - Convert C/C++ code to assembly language

C Code

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;

Variables

Basic variable declaration and arithmetic. This shows how local variables are allocated on the stack and how simple arithmetic operations translate to assembly instructions.

Key Concepts:

  • Stack Allocation: Local variables are stored on the stack, typically accessed via offsets from the base pointer (rbp)
  • Register Usage: The compiler uses registers for temporary calculations to improve performance
  • Arithmetic Instructions: Simple operations like addition compile to single instructions like add or lea

Reference: Simple C examples and their Assembly output from GCC

C Code

int main() {
    int a = 10;
    int b = 20;
    int c = a + b;
