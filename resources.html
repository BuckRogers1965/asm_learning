Why Use -O0 (No Optimization)?

All examples in this tutorial are compiled with -O0 (no optimization). This makes the assembly:

  • Easier to read and understand
  • Closely match the structure of the C code
  • Show explicit stack operations and variable storage
  • Not optimized away or reordered

Once you understand the basics, try compiling with -O1, -O2, and -O3 to see how the compiler optimizes code!
